# Contrat API atelier M24 — cockpit

Source de vérité : routeurs FastAPI montés dans
`backend/src/cti_app/api/main.py` et leurs modèles Pydantic. Toutes les
fonctions passent par `investigationRequest` (`frontend/src/api/investigation.ts`)
via `client.ts`, qui normalise les refus en `WorkshopApiError`
`{ status, code, details }` (`details` = `detail.details`, `null` sinon ;
`status: 0` / `code: "network_error"` pour un échec de transport).

- `CommonErrorCode` = `verified_human_operator_required`,
  `agent_session_required`, `agent_session_signature_invalid`,
  `agent_session_binding_mismatch`, `agent_session_inactive`,
  `agent_session_lease_stale`, `agent_sessions_unavailable`,
  `agent_sessions_require_authenticated_identity`, `investigation_not_found`,
  `idempotency_conflict`, `investigation_api_error` (corps de validation
  FastAPI sans `detail.code`), `network_error`.
- Chaque module exporte sa fabrique de clés TanStack Query
  (`<module>Keys`), ses fonctions de requête et ses hooks. Les hooks de
  lecture utilisent `useQuery`; les écritures `useMutation` et invalident les
  clés documentées dans le module (`onSuccess`).

## Légende

- **IK** : en-tête `Idempotency-Key` requis par la route.
- **CAS** : champ(s) de version/hash à envoyer.
- Les codes listés par route s'ajoutent à `CommonErrorCode`.
- Tests : `src/features/investigation/api/<fichier>.test.ts` (fetch mocké,
  aucune requête réelle).

## Non exposées à l’UI (raison)

- `POST …/agent-sessions/{sid}/tool-calls` : shim D7 signé ; le secret de
  session ne doit jamais atteindre le navigateur.
- `POST …/agent-sessions/{sid}/instructions` avec `action: "ack"` :
  acquittement opérateur signé ; seule la moitié humaine `enqueue` est exposée.
- `POST …/agent-sessions/{sid}/reconcile` : réconciliation opérateur signée,
  jamais de relance automatique.
- `POST …/agent-sessions/{sid}/collect` : collecte de résultats signée côté
  hôte.
- `POST …/tasks/{tid}/commands` et `POST …/handoffs` en variante opérateur
  signée : mêmes chemins que les commandes humaines, mais l’identité vient de
  la session HMAC, pas du navigateur.
- `/api/investigations/{id}/operator/**` : surface opérateur historique
  (contexte, outils, invocations, statut), hors contrat cockpit M24.
