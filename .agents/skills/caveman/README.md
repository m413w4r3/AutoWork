# caveman (optional response style)

`/caveman` is an explicit opt-in terse conversational writing style, not
a context-compression algorithm, proof of token savings or a coding-agent
optimization. It does **not** activate because a user asks for fewer tokens
or concise coding reports.

See [SKILL.md](SKILL.md). Keep factual precision, uncertainty, safety and
evidence qualifications unchanged. No measured aggregate savings or
quality-equivalence figure is asserted.
