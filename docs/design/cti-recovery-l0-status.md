## Findings for L1/L2

- The prompt and parser version bumps are present. The existing code therefore invalidates incompatible extraction/reference identities as intended; this was not a missing-bump defect.
- The gateway retries when the bridge reports a terminal `failed` status and supplies a bridge run ID. Unit tests validate local state transitions with fakes, but do not establish that the real bridge's `failed` status proves no answer can still be recovered. L2 should verify that external contract before relying on the retry path during a real run.
- L1 remains necessary for SYNTHESIS and EDITORIAL_ENRICHMENT transport. The current synthesis path still expects structured output (`test_model_gateway_receives_synthesis_proposal_as_structured_schema`); L0 did not broaden the wire-format change to those stages.
- PostgreSQL restart/reuse scenarios and all real bridge/model runs remain unverified. The Docker socket failure prevented checking whether the local integration infrastructure was available.
