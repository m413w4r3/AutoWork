## Denominators and test levels

The task cites 303 backend test files. On this checkout, the file inventory is 305 non-integration `test_*.py` files plus 61 under `backend/tests/integration` (366 total), with 3,698 + 232 = 3,930 test-function definitions. There are 403 Python files in `backend/tests` including helpers and conftests. The audit searched that current tree and traced the scope-relevant candidates below; this is not a manual review of every unrelated test body. Parameterized cases are counted once as definitions.

- **unit:** pure builders, validators, serializers, or policy functions.
- **in-memory fake:** repository, UOW, blob store, recorder, or session is an in-process stand-in.
- **fake transport:** injected transport records the prompt/call; no live provider is reached.
- **replay:** deterministic idempotency/checkpoint replay against fakes or persisted test fixtures.
- **real disposable PostgreSQL / integration:** the integration fixture creates a uniquely named database, migrates it to `head`, and drops it afterward when `TEST_POSTGRES_ADMIN_DSN` is configured. These tests were inspected, not run.
- **real Typst/PDF:** subprocess compilation and PDF text/render inspection with synthetic publication inputs; this is not a database or provider integration.
- **SQLite:** no SQLite-backed test was found in the focused surface. A compiled PostgreSQL predicate or `SessionSpy` is not PostgreSQL evidence.

## Highest-risk survivors

1. **Credential disclosure:** the ordinary JSON credential cases are asserted, but escaped serialized JSON remains the S2 gap; a green redaction suite does not cover it.
2. **Audit provenance:** deterministic export tests start from hand-built snapshots and cannot detect a broken or mis-scoped PostgreSQL reader.
3. **Pagination integrity:** broad hash/manifests are tested in pure and fake-repository code; the real PostgreSQL API test does not walk a chained multi-page result.
4. **Publication completeness:** current tests cover a small real PDF chronology and a PG V6 document separately, not an exhaustive chronology in the final published PDF.
